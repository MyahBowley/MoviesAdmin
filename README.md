# MoviesAdmin
This repository is apart of my semester project for my Web Application Programming course. Our assignment is to build a movie review website similar to [Rotten Tomatoes](https://www.rottentomatoes.com/). This project uses the [Scrum methodology](https://www.scrum.org/resources/what-scrum-module), and is broken down into 4 sprints. 

This repository will be for the **Adminstration portion** of the system I will be creating.  This is where people will log in, and edit records. It will hacve CRUD functionality to manage the movie data. This portion of my final project will become the foundation before moving on to more complex features.

## Features
Although this project is still ongoing, the final result should have:
* The App's users can **create**, **read**, **update**, and **delete** movie data stored in a database.
* The movie data includes title, synopsis, genre, age rating, runtime hours and minutes, and release date.
* The admin app displays a summery list of all the movies in the database.

## Technologies Used
